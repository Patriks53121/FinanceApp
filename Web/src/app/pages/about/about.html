About

This app is made for people who want to understand more about their finances and how to manage them better. It provides statistics and graphs to help users better understand their money spending and income. Also app provides tips how to save money, and with this tips app help users manage their finances better. App is secure and private, all data is stored locally on the user's device and is not shared with anyone else, app not require private data from users, app don't have access to the internet, except for checking for updates, and downloading them, but only from user allowance. App is open source, and all code is available on GitHub, so anyone can check how it works, and if they want, there is instructions what is where located, and user can make changes to the app, to improve it for personal use, but it can't be used for commercial purposes, because of the license.
