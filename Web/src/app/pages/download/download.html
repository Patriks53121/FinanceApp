How to download?

GitHub

You can download the source code from github, make changes, or just build the app by yourself.

  1. Click button "Download source"
  2. Click green button "Code" and chose "Download ZIP"
  3. Extract the ZIP file
  4. Open the extracted folder with code editor
  5. Install all necessary plugins and packages to your computer
  6. Review code, there is instruction about it, make changes if want
  7. Connect your device to your computer via cable
  8. On phone allow debug
  9. Select your phone for debug
  10. Run and build project to your phone
  11. App will open automatic, and in future will be on your home screen

APK file

You can download directly the APK file and install it on your device.
Steps:

  1. Click button "Download APK"
  2. Download APK file
  3. Open it and just download it
  4. On desktop will appear app
